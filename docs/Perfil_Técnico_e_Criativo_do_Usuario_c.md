# 🧠 Perfil do Usuário — Análise Técnica e Criativa

## 🎯 Visão Geral
Desenvolvedor de jogos com perfil técnico forte, atuando de forma híbrida entre:
- Programação
- Game Design
- Direção de Arte

Abordagem orientada a sistemas, com foco em consistência, escalabilidade e produto final.

---

## 🧠 Perfil Técnico (Engenharia de Software para Jogos)

**Stack principal:**
- OpenFL (Haxe)
- Godot Engine (GDScript)

**Características:**
- Estrutura código em classes e sistemas bem definidos
- Preocupação com:
  - Escalabilidade (resolução, layout responsivo)
  - Organização de assets
  - Performance e consistência
- Implementa regras completas de jogo (não apenas protótipos)

**Mentalidade:**
> Engenharia de sistemas aplicada a jogos, não apenas scripting.

---

## 🎮 Perfil de Game Designer (Prático)

**Foco em sistemas de jogo:**
- Bingo
- Keno
- Slots
- Pachinko

**Elementos recorrentes:**
- Loop de gameplay bem definido:
  - Entrada (créditos)
  - Ação (jogada)
  - Resultado (recompensa)
- Regras claras e múltiplas condições de vitória

**Preocupações:**
- Feedback visual (highlight, UI states)
- Feedback sonoro (variações de estilo)
- UX (bloqueios, estados de botão, telas auxiliares)

**Perfil:**
> Game Designer técnico, orientado à implementação.

---

## 🎨 Perfil Visual (Direção de Arte)

**Estilo predominante:**
- 2D estilizado / cartoon
- Temática de cassino (madeira, pedra, dourado, elementos de sorte)

**Foco em:**
- Texturas (pedra, madeira, musgo)
- Consistência visual entre elementos
- Assets com fundo transparente
- Fidelidade a proporções e identidade

**Abordagem:**
> Criação de identidade visual de produto, não assets isolados.

---

## ⚙️ Perfil de Produção (Produto)

**Comportamento:**
- Solicita documentação técnica
- Estrutura projetos completos
- Organiza sistemas para reutilização

**Preocupações:**
- Monetização (créditos, apostas)
- Clareza de regras
- Experiência do jogador

**Perfil:**
> Mentalidade de produto/jogo comercial.

---

## 🧩 Perfil Cognitivo

**Características:**
- Altamente orientado a detalhes
- Iterativo (refina continuamente)
- Pragmático (foco em resultado utilizável)
- Exigente com qualidade

**Padrão de trabalho:**
> Não aceita soluções incompletas ou superficiais.

---

## 📉 Pontos de Atenção

- Tendência a:
  - Over-engineering precoce
  - Foco excessivo em polish visual antes do core estar fechado
- Forte atuação no nível micro (detalhes), com risco de atrasar decisões macro
